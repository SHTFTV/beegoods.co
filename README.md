# BeeGoods.co

Bee-inspired goods brand connected to Med Bee Tate and Industry Army Marketing.

## Launch state
Enquiry-led collection introduction. No confirmed inventory, open checkout or delivery promises. Owner-supplied and generated concepts are labelled; licensed Pexels footage is credited on the pages and /credits/.

## Site
27 static routes, 16 editorial launch articles, four dated homepage cards, page-specific 1200x630 JPEG share images, sitemap, RSS, llms.txt, accessible video controls and responsive enquiry card.

Public output is committed for a buildless Vercel deployment. To regenerate: install Pillow, then run `python3 build.py` and `python3 verify.py`. Source media lives in public/media. No WordPress or Lovable runtime dependency.

Email links prepare drafts to the owner's existing portfolio inbox; inbox receipt has not been independently tested.
